# Responsive Conditions

> Hide blocks on different devices. Show or hide content on **Desktop**, **Tablet**, and **Mobile**.

## What Is This?

Hide blocks on specific devices. Perfect for cleaning up mobile layouts or showing desktop-only content.

👉 **Just toggle to hide. No coding needed.**

![Responsive Conditions Overview](https://wpspectra.com/wp-content/uploads/2024/12/responsive-conditions-overview.gif)

---

## How To Use

1. **Select any block** in the editor
2. **Open the Settings panel** (sidebar)
3. **Find "Responsive Conditions"** and expand it
4. **Toggle the hide options:**
   - Hide on Desktop (big screens)
   - Hide on Tablet (medium screens)
   - Hide on Mobile (small screens)
5. **Preview** using WordPress device buttons

![Responsive Conditions Panel](https://wpspectra.com/wp-content/uploads/2024/12/responsive-conditions-panel.webp)

> **Tip:** You can hide on multiple devices! Hide on Desktop AND Mobile to show only on Tablet.

---

## When To Use

**Clean up mobile:**
- Hide complex tables on phones
- Remove large images on mobile
- Hide extra buttons on small screens

**Desktop-only content:**
- Show sidebars only on desktop
- Display detailed info on big screens
- Add extra navigation for desktop users

**Tablet-specific:**
- Different layouts for tablets
- Tablet-optimized content
- In-between screen adjustments

## Supported Blocks

**All Spectra Free Blocks:**
- Accordion, Button, Buttons, Container, Content
- Countdown, Google Map, Icon, Icons, List
- Modal, Separator, Slider, Tabs

**All Spectra Pro Blocks:**
- Loop Builder (with filters, pagination, search, sort)

**WordPress Core Blocks:**
- Image

---

## Tips

- **Start with desktop** - design for big screens first
- **Test on real devices** - not just browser preview
- **Don't hide important content** - always provide alternatives
- **Use sparingly** - hiding too much can confuse users

---

## Troubleshooting

**Block not hiding?**
- Check you're previewing the right device size
- Clear cache and try again

**Don't see the panel?**
- Not all blocks support this feature
- Make sure you selected a supported block

---

## FAQ

**Can I hide on multiple devices?**
Yes! Mix and match any combination.

**Will this slow down my site?**
No, it uses fast CSS to hide content.

**Does hidden content still load?**
Yes, it loads but doesn't show. For true speed gains, remove blocks entirely.
